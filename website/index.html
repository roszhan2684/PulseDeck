What’s inside

Built like a small team obsessed over it.

Swipe deck

Physics, not slideshows.

One shared position drives every card on the UI thread. Velocity-aware commits, rubber-banding at the edges, swipe back to the previous card.

Reactions

🔥 Double-tap. 😂 Hold. 💀 Burst.

Optimistic updates with rollback. Double-tap only adds, so rapid taps never undo a reaction.

Realtime chat

Instant, then confirmed.

Client IDs reconcile optimistic and server messages. No duplicates, tap to retry, reconnect backfill.

Leaderboard

Rows that physically move.

Live score events, competition ranking, rolling digits and podium styling for the week’s leader.

Onboarding

Seven steps, zero friction.

Spring progress, async username checks, join-by-code, and a coordinated hand-off into the app.

Accessibility

Reduced Motion is a first-class mode.

Particles, parallax and rotation step aside for gentle fades while every action keeps working. VoiceOver labels on everything, gesture-free alternatives, 44 pt touch targets, 4.6:1+ contrast.

Motion system

Four springs. Zero magic numbers.

These balls use the app’s exact spring tokens from theme/motion.ts, converted to CSS. Click to replay.
